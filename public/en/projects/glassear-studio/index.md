# Glassear Studio - Natural Language to Interactive XR

_AI & XR_

Glassear Studio translates natural-language intent into structured, synchronized changes to interactive XR applications.

**Outcome:** An AI-native platform for building and modifying interactive XR applications across a web authoring environment and Unity runtime.

## Problem

Creating interactive XR applications normally requires specialized tooling and manual coordination between authoring systems and runtime state.

## What I built

Glassear Studio translates natural-language intent into structured, synchronized changes to interactive XR applications.

- Natural-language-to-application workflows
- AI Planner and Intent Graph
- Agent and MCP tool architecture
- Structured scene/runtime modifications
- Hybrid deterministic and LLM architecture

## Architecture

An AI Planner and Intent Graph coordinate tool-based operations, MCP integrations, structured scene patches and runtime synchronization between a TypeScript/React/Node.js web platform and Unity.

## AI / agentic component

LLMs interpret intent and plan tool calls within explicit system constraints.

## Deterministic components

Typed operations, validation, reconciliation and runtime acknowledgements control how planned changes become scene state.

> Reasoning proposes changes; deterministic contracts validate, apply and synchronize them.

## Stack

TypeScript, React, Node.js, Unity, Python, PostgreSQL, MCP, LLM APIs, XR
